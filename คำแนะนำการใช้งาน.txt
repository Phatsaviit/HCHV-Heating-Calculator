========================================================================
คู่มือและคำแนะนำการใช้งานโปรแกรม Heating Cycle Test Analyzer
โปรแกรมสรุปผลการทดสอบ Heating Cycle Voltage Test (IEC 60840 / IEC 60502-2)
========================================================================

[ วิธีการใช้งานโปรแกรม ]
1. ดับเบิลคลิกที่ไฟล์ 'HeatingCycleAnalyzer.exe' เพื่อเปิดโปรแกรม
2. กดปุ่ม 'Browse File...' เพื่อเลือกไฟล์ Excel รายงานผลการทดสอบ (เช่น HCHV 115 kV.xlsx)
3. เลือกมาตรฐานการทดสอบ (Test Standard):
   - Auto-detect (แนะนำ): ระบบจะตรวจสอบจากระดับแรงดันทดสอบ (U test) ในไฟล์โดยอัตโนมัติ
   - HV Cable (IEC 60840 / 62067): สายไฟฟ้าแรงสูง รอบละ 24 ชม. (ร้อน >= 8 ชม., ระบาย >= 16 ชม.)
   - MV Cable (IEC 60502-2): สายไฟฟ้าแรงดันปานกลาง (ร้อน >= 8 ชม. คงที่ >= 2 ชม., ระบายธรรมชาติ)
4. กดปุ่ม '[ Run Analysis & Add Summary Sheet ]'
5. หลอดสถานะ (Progress Bar) จะแสดงความคืบหน้า 0-100%
   เมื่อเสร็จสิ้น ระบบจะเพิ่มแผ่นงานสรุป 'Cycle_Summary' เข้าไปเป็นหน้าแรกของไฟล์ Excel โดยอัตโนมัติ
6. กดปุ่ม 'Open Analyzed Excel File' เพื่อเปิดดูรายงานผลใน Excel ได้ทันที

------------------------------------------------------------------------
[ คำอธิบายความหมายของตัวแปรและข้อมูลในรายงาน (Parameter Definitions) ]
------------------------------------------------------------------------

1. Cycle : หมายเลขรอบการทดสอบ
   - ลำดับรอบของการทดสอบความร้อน ตั้งแต่ Cycle 1 ถึง Cycle 20 (หรือเท่าที่มีข้อมูล)

2. Status : สถานะของแต่ละรอบ
   - Completed   : รอบการทดสอบเสร็จสมบูรณ์ ครบทั้งช่วงจ่ายกระแส (Heat) และช่วงระบายความร้อน (Cool)
   - In Progress : รอบการทดสอบกำลังดำเนินการอยู่ (มีข้อมูลบางส่วน เช่น กำลังจ่ายกระแสหรือกำลังระบายความร้อน)
   - Pending     : รอบการทดสอบที่ยังมาไม่ถึง หรือยังไม่มีข้อมูลบันทึกในไฟล์

3. T1 (Heat Start) : เวลาและกระแสเริ่มต้น
   - จุดเวลาที่เริ่มจ่ายกระแสความร้อนเข้าสายเคเบิล
   - โปรแกรมนับเมื่อค่ากระแสไฟฟ้า (I test) ไต่ระดับขึ้นถึงค่า Setpoint (เกณฑ์ I test >= I set - 0.05 kA)

4. T2 (95°C Target) : เวลาและค่าอุณหภูมิ ณ จุดเริ่มนับช่วงคงที่
   - จุดเวลาที่อุณหภูมิตัวนำ (Conductor Temperature: T1, T2 หรือ T3) เส้นใดเส้นหนึ่งแตะระดับ 95.0°C เป็นครั้งแรก
   - ถือเป็นจุดเริ่มต้นในการนับระยะเวลาช่วงรักษาอุณหภูมิคงที่ (Hold Phase)

5. T3 (Heat Stop) : เวลาที่หยุดจ่ายกระแส
   - จุดเวลาที่ระบบตัดการจ่ายกระแสความร้อนเข้าสายเคเบิล
   - โปรแกรมตรวจจับเมื่อกระแสไฟฟ้าลดลงต่ำกว่าระดับสัญญาณรบกวน (Noise floor < 0.100 kA)

6. T4 (Cool End) : เวลาสิ้นสุดการระบายความร้อนและอุณหภูมิต่ำสุด
   - จุดเวลาสิ้นสุดการระบายความร้อนของรอบนั้นๆ โดยนับถึงจุดก่อนที่รอบถัดไปจะเริ่มเร่งกระแสขึ้นมาใหม่
   - ใช้บันทึกอุณหภูมิสุดท้ายของสายเคเบิลและอุณหภูมิห้องก่อนขึ้นรอบใหม่

7. Ramp Duration : เวลาช่วงเร่งความร้อน (T1 -> T2)
   - ระยะเวลาตั้งแต่เริ่มจ่ายกระแส (T1) จนกระทั่งอุณหภูมิตัวนำขึ้นถึง 95.0°C (T2)

8. Hold Duration : เวลาช่วงคงความร้อน (T2 -> T3)
   - ระยะเวลาที่รักษาอุณหภูมิตัวนำให้อยู่ในช่วงอุณหภูมิทดสอบ (>= 95.0°C) จนกระทั่งหยุดจ่ายกระแส (T3)
   - เกณฑ์มาตรฐาน: ต้องคงความร้อนไม่น้อยกว่า 2 ชั่วโมง (>= 2h) ทั้งมาตรฐาน HV และ MV

9. Total Heat Duration : เวลาช่วงจ่ายกระแสรวม (T1 -> T3)
   - ระยะเวลารวมทั้งหมดในการจ่ายกระแสความร้อนในรอบนั้น (Ramp Duration + Hold Duration)
   - เกณฑ์มาตรฐาน: ต้องจ่ายกระแสความร้อนรวมไม่น้อยกว่า 8 ชั่วโมง (>= 8h)

10. Cooling Duration : เวลาระบายความร้อน (T3 -> T4)
    - ระยะเวลาที่ปล่อยให้สายเคเบิลระบายความร้อนตามธรรมชาติหลังจากตัดกระแส (T3) จนถึงสิ้นสุดรอบ (T4)
    - เกณฑ์มาตรฐานสาย HV: ต้องระบายความร้อนไม่น้อยกว่า 16 ชั่วโมง (>= 16h หรือ 960 นาที)
    - เกณฑ์มาตรฐานสาย MV: ปล่อยให้สายเคเบิลเย็นตัวลงตามธรรมชาติต่อเนื่อง (>= 3h)

11. Total Cycle Duration : เวลารวมต่อรอบ
    - ระยะเวลารวมทั้งหมดของรอบการทดสอบนั้น (Total Heat Duration + Cooling Duration)
    - สาย HV รวมรอบละ 24 ชั่วโมง (24h 00m) ตามข้อกำหนดมาตรฐานสากล

12. I ramp avg [kA] : กระแสเฉลี่ยช่วงเร่ง
    - ค่าเฉลี่ยของกระแสไฟฟ้าทดสอบ (I test) ตลอดช่วงเร่งอุณหภูมิ (T1 ถึง T2)

13. I hold avg [kA] : กระแสเฉลี่ยช่วงคงที่
    - ค่าเฉลี่ยของกระแสไฟฟ้าทดสอบ (I test) ตลอดช่วงรักษาอุณหภูมิตัวนำให้คงที่ (T2 ถึง T3)

14. I heat avg [kA] : กระแสเฉลี่ยช่วงจ่ายกระแสทั้งหมด
    - ค่าเฉลี่ยของกระแสไฟฟ้าทดสอบ (I test) ตลอดช่วงเวลาที่จ่ายกระแสความร้อนทั้งหมด (T1 ถึง T3)

15. Compliance : สรุปผ่าน/ไม่ผ่านตามเกณฑ์มาตรฐาน
    - Pass : ผ่านเกณฑ์ระยะเวลาตามที่มาตรฐานกำหนด
    - Fail : ไม่ผ่านเกณฑ์ (เช่น เวลาคงที่น้อยกว่า 2 ชม. หรือเวลาร้อนรวมน้อยกว่า 8 ชม.)
    - '-'  : อยู่ระหว่างการทดสอบ (In Progress) หรือยังไม่ถึงรอบนั้น (Pending)

------------------------------------------------------------------------
[ ตัวแปรสำคัญอื่นๆ ในตารางสรุปผล Excel ]
------------------------------------------------------------------------
- Row No.            : หมายเลขแถวจริงในแผ่นงาน 'Test_Record' (สามารถคลิกเพื่อ Link ไปยังแถวนั้นได้ทันที)
- T 1, T 2, T 3 [°C] : อุณหภูมิของตัวนำที่จุดวัดที่ 1, 2 และ 3
- T avg [°C]         : อุณหภูมิเฉลี่ยของตัวนำ (Conductor Average Temperature)
- TC sheath ref [°C] : อุณหภูมิเปลือกนอกของสายเคเบิลอ้างอิง (Reference Cable Sheath)
- TC sheath test [°C]: อุณหภูมิเปลือกนอกของสายเคเบิลทดสอบ (Test Cable Sheath)
- T amb [°C]         : อุณหภูมิแวดล้อม (Ambient Temperature)
- U test [kV]        : แรงดันไฟฟ้าทดสอบ ณ จุดเวลานั้น
- I setpoint [kA]    : ค่าเป้าหมายกระแสไฟฟ้าที่ตั้งไว้ในการทดสอบ

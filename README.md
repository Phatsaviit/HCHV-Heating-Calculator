# Heating Cycle Test Current Calculator (IEC 60840)

เครื่องมือคำนวณและจำลองกระแสจ่ายทดสอบความร้อนสายไฟฟ้าแรงสูง (Heating Cycle Voltage Test) อ้างอิงตามมาตรฐาน IEC 60840 Clause 12.4.6 และ Annex A

---

## ฟังก์ชันการทำงาน

1. **คำนวณกระแสทดสอบ 2 จังหวะ**:
   - ปรับอุณหภูมิห้อง ($T_{amb}$), อุณหภูมิตัวนำเป้าหมาย ($T_{target}$), และเวลาช่วงเร่ง ($T_1 \to T_2$)
   - คำนวณกระแสช่วงเร่ง ($I_{boost}$) เพื่อให้อุณหภูมิตัวนำถึง 95 °C ภายในเวลาที่กำหนด
   - คำนวณกระแสช่วงคงที่ ($I_{hold}$) เพื่อรักษาอุณหภูมิให้อยู่ในกรอบ 95 - 100 °C ไม่น้อยกว่า 2 ชั่วโมง
2. **กราฟผลการทดสอบ 1 Cycle (Cycle 3)**:
   - แสดงข้อมูลบันทึกจริงจากห้องทดสอบเปรียบเทียบกับเส้นจำลองตามสเตจ T1 ถึง T4
   - รองรับการแสดงผลทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ
3. **สูตรแปลงอุณหภูมิผิวเปลือกนอกสู่ตัวนำ (Method 2 per Annex A.3.2)**:
   - คำนวณอุณหภูมิตัวนำภายในจากค่าเซนเซอร์ผิวเปลือกนอก ($TC_{sheath}$):
     $$T_{conductor} = TC_{sheath} + 1.81 \times (TC_{sheath} - T_{amb})$$
